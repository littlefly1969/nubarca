# NubArca agent instructions

Read `CLAUDE.md` and `docs/current-work.md` before starting repository work.

Before every production deployment, fastdeploy, container rebuild, release-pin
change or production migration, read `deploy/FAST_DEPLOY.md` in full
immediately before running production commands. Treat that runbook as the
deployment source of truth; do not deploy from remembered commands or from
`scripts/prod-dc.sh` alone.
